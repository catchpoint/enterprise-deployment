# enterprise-deployment
This repo includes Kubernetes, Helm charts, deployment scripts

## Shell
This directory includes a POSIX-compliant installation script that is usable on Debian (Ubuntu) and RedHat (RHEL, Oracle, Rocky) Linux distributions. See [the Shell readme for more](./Shell/README.md).

## PowerShell
This directory includes a PowerShell launcher that runs Catchpoint Enterprise images through WSL containers (`wslc.exe`). See [the PowerShell readme for more](./PowerShell/README.md).
